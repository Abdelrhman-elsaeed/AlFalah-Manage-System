# نظام الفلاح — النسخة المطبّقة في الرئيسية

تم تطبيق السكشن في الصفحة الرئيسية بعد المقدمة وقبل «رؤيتنا»، بناءً على موافقة المستخدم الصريحة على الدمج.

التحديث التالي يفصل الهيرو عن الحركة بمقدمة فاتحة بعنوان «نظام الفلاح» ووصف مختصر للفائدة. للقسم رابط مستقل في قائمة الرئيسية وسهم نهاية الهيرو؛ «رؤيتنا» يحتفظ بعنوانه ورابطه المستقلين. ارتفاع منطقة الحركة وحدها يطابق «رؤيتنا»، والمقدمة تضيف مساحة مستقلة فوقها. القائمة المطوية تبدأ عند 1024px لاستيعاب الرابط الجديد على التابلت. نتائج مراجعة عشرة مقاسات والتنقل محفوظة في reference/site-inspection/section-divider-verification.json، مع لقطتي section-divider-desktop.png وsection-divider-mobile.png.

افتح الموقع المحلي: http://localhost:4200/#system-story

## التعديلات النهائية

- إصلاح قص النص العربي من اليمين: تعويض عمق المكعب عن تكبير المنظور، وقياس النص مع هامش داخلي.
- استبدال الخطوط البيضاء بعملة ثلاثية الأبعاد ذات حافة ذهبية، وجه يحمل الشعار الأصلي، دوران ولمعة متحركة.
- استبدال تكبير كلمة «رعاية» بانتقال مقنّع يبدأ من مساحة الهاتف، مع ظهور محتواه أثناء الانتقال.
- نقل تصريح الخروج إلى عمود النص؛ البوابة والحارس والطالب ظاهرون دون تغطية الورقة.
- تكرار مستمر لدورة 47 ثانية؛ جسر DOM يعرض وضع البداية نفسه قبل إعادة الزمن إلى الصفر.
- الارتفاع يطابق «رؤيتنا» الفعلية عبر ResizeObserver؛ التخطيط يعاد ترتيبه للهاتف.

## التشغيل والموارد

السكشن HTML/CSS/SVG/Three.js أصلي داخل Angular، دون فيديو أو iframe. الخطوط وGSAP وThree.js محلية. اسم خط الحركة FalahMotion يعزل إعداداته عن خطوط التطبيق.

يبدأ التحميل عند الاقتراب من السكشن، وتعمل الحركة عند ظهوره وتتوقف خارج الشاشة أو عند إخفاء التبويب. زر الإيقاف والانتقال بين المحطات متاحان. عند تفضيل تقليل الحركة تظهر خلاصة الفوائد ثابتة، ولا يُحمّل Three.js إلا إذا اختار الزائر التشغيل. يوجد بديل رسومي عند غياب WebGL.

التنقل خارج الصفحة يوقف الحركة ويفصل المراقبين والأحداث ويحرر موارد WebGL. يعاد إنشاء السكشن عند العودة.

## التحقق

- بناء Angular بوضع development: ناجح.
- اختبارات الصفحة الرئيسية المعزولة: 17/17 ناجحة.
- فحص HyperFrames: ناجح، مع ملاحظات تنظيمية غير مانعة.
- اختبار الرئيسية الفعلية في Chrome: لا أخطاء JavaScript؛ تطابق الارتفاع دون تجاوز أفقي عند عروض 1914 و1600 و1280 و1024 و768 و390.
- فحص وجهي النص المتبادل: هامش آمن في الكمبيوتر والهاتف.
- تصريح الخروج: مساحة التداخل مع رسم البوابة صفر في الكمبيوتر والهاتف.
- عبور نهاية الدورة ثلاث مرات متتالية: ناجح مع استمرار التشغيل.
- الخروج إلى صفحة الدخول ثم العودة: تحرير النسخة القديمة وإعادة إنشاء الجديدة بنجاح.
- الإيقاف، العودة للشاشة، تقليل الحركة والبديل دون WebGL: ناجحة.

بناء production يتوقف عند حدود CSS الموجودة مسبقًا في visit-workspace (34.50KB مقابل حد 32KB) وstorage-page (39.34KB مقابل حد 32KB). لم نغيّر هذين الملفين أو حدود البناء. التشغيل الشامل لكل اختبارات المشروع يتعطل كذلك بسبب أخطاء أنواع في اختبارات التخزين؛ لذلك شُغّلت اختبارات الرئيسية بإعداد معزول محفوظ.

## الأدلة وإعادة التوليد

- reference/site-inspection/verification.json — اختبار الرئيسية والتكرار والنصوص والبوابة والتنقل.
- reference/site-inspection/*.png — لقطات الكمبيوتر والهاتف.
- reference/site-landing-focused-tests.log — نتيجة اختبارات الرئيسية.
- reference/section-check.json — فحص HyperFrames.
- reference/section-browser-verification.json — سلوك المراجعة، تقليل الحركة والبديل الرسومي.
- reference/site-section-manifest.json — بصمة الأصول المطبّقة.

مصادر التأليف هنا في section-content.cjs وsection.css وsection-timeline.js وsection-player.js وsection-world.mjs. مكوّن Angular في frontend/src/app/features/landing/components/system-story والأصول المولّدة في frontend/src/assets/motion/falah.

بعد تعديل التأليف، من مجلد frontend:

```powershell
npm run build:motion
```

النسخة المطبّقة لا تعتمد على خادم المعاينة أو وجود مجلد docs وقت التشغيل. معاينة التأليف المستقلة تظل متاحة على http://127.0.0.1:8877/section-review.html عند تشغيل خادم المراجعة. الدمج محلي داخل المشروع؛ لم يُنفّذ نشر خارجي.

## دقة القصة

الفوائد: أوراق منظمة، جهد إداري أقل، أمان الطالب ورعاية أقرب. القصة تمر بالكادر، الوصول والحضور، الطابور، الحصص والمناوبة، رصد المعلم ومراجعة الموجّه، ولي الأمر، التحقق عند الانصراف، ثم الملفات والتقارير.

البصمة استيراد سجل زاجل، وكشف الغياب اليومي مستقل. ملاحظة المعلم ومراجعة الموجّه والتواصل المعتمد خطوات منفصلة. اعتماد التصريح يسبق التحقق والعبور وتسجيل الخروج الفعلي. أرشفة PDF تخص تقارير الزيارات المعتمدة عند تفعيل التكامل. الأمثلة تمثيلية ولا تستخدم بيانات طلاب حقيقية أو نسب توفير مصطنعة.
