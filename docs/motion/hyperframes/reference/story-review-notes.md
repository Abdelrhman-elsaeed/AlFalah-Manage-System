# نظام الفلاح — من أول حضور إلى آخر أثر

**الحالة:** فيلم معاينة جديد مدته ٦٤ ثانية، بانتظار اعتماد الفيديو ومكانه. لم يتم تعديل الصفحة الرئيسية أو ربط الفيديو بالتطبيق.

**المعاينة:** http://127.0.0.1:8877/review.html

**الفيديو:** [نسخة الويب MP4](renders/05-alfalah-school-day.mp4) · [النسخة الأصلية](renders/05-alfalah-school-day-master.mp4) · [نسخة الهاتف](renders/05-alfalah-school-day-mobile.mp4)

## ما تغيّر

- بناء القصة على تسلسل اليوم: استعداد الكادر 06:40، وصول الطلاب 06:50، الطابور 07:00، الحصص 07:30، الفصل 08:15، متابعة الطالب 09:10، الانصراف 12:45، وحفظ العمل 13:00. الأوقات توضيحية.
- افتتاحية وختام باسم **نظام الفلاح**، وعناوين عربية كبيرة ورسالة «من أول حضور… إلى آخر أثر».
- إنفوجرافيك لحضور الموظفين، وغياب الطلاب، وعلاقة المعلم بالموجّه وولي الأمر، وخطوات التصريح والخروج.
- زوم داخل حروف الكلمات باستخدام أقنعة SVG فعلية، وانتقالات دائرية وشبكية وخطية ومن ورقة التصريح إلى الأرشيف.
- كاميرا قريبة للبصمة، وواجهة ثم لقطة علوية للطابور، وزوايا أمامية وجانبية للفصل والموجّه والبوابة.
- عرض استيراد سجل زاجل ومتابعة التأخر بدقة، مع تمييزه عن كشف الحضور اليومي. الخروج الفعلي يأتي بعد تحقق الحارس والعبور.
- فصل الأرشيف بصريًا إلى مجسّم للمكتبة وفهرس رقمي وخصائص الملفات.
- استبعاد الفيديوهين السابقين ولقطة شاشة الجدول التي طلبت حذفها من المعاينة الحالية.

## المكان المقترح

قسم **«يومك مع نظام الفلاح»** مباشرة بعد مقدمة الصفحة الرئيسية، قبل تفاصيل المزايا. مشغّل كبير يبدأ بالضغط، مع صورة معاينة ثابتة ونهاية تحتفظ باسم النظام. طول القصة يناسب مشاهدة مقصودة؛ لذلك لا يبدأ تلقائيًا ولا يكرر نفسه تلقائيًا.

## التحقق والأداء

- HyperFrames 0.8.163، 1600×900، 30 إطارًا/ثانية، 1920 إطارًا. الرندر استخدم hardware GPU واستغرق نحو دقيقتين ونصف.
- نسخة ويب 1280×720 بصيغتي MP4 وWebM، ونسخة هاتف 640×360 وصورة WebP. `preload="none"`، دون تشغيل تلقائي، ودون تحميل Three.js أو GSAP في الموقع عند اعتماد فيديو مشفّر.
- فحص HyperFrames نجح دون أخطاء في lint/runtime/layout/contrast. توجد توصيات تنظيمية لتقسيم المشاهد، وتحذير لتكرار الشعار، وتداخل نصي مقصود أثناء تكبير قناع الكلمة؛ التفاصيل في `reference/story-check.json`.
- فحص ثبات الحركة نجح عند الانتقال A → B → A بنفس بصمة صورة الإطار. لقطات تشغيل HyperFrames محفوظة في `reference/story-runtime-snapshots/`.
- معلومات الترميز وفك الترميز الكامل: `reference/story-delivery-manifest.json`.
- فحص تشغيل المتصفح والهواتف وأزرار المحطات وMP4 وbyte ranges: `reference/story-browser-verification.json`.
- اللقطات المفكوكة من الفيديو الفعلي: `reference/story-decoded/`.

## إعادة التشغيل

```powershell
cd D:\AlFalah-Manage-System\docs\motion\hyperframes
npm run build
npm run check
npm run review
```

الرندر وإعداد نسخ الويب عند تعديل المصدر:

```powershell
$env:HYPERFRAMES_BROWSER_PATH='C:/Program Files/Google/Chrome/Application/chrome.exe'
npx --yes hyperframes@0.8.163 render alfalah-story --quality looks --workers 2 --output renders/05-alfalah-school-day-master.mp4
python -X utf8 encode-story.py
node build-story-review.cjs
node verify-story.cjs
```

مصادر القصة وتفاصيل الإخراج ودقة المزايا في [STORY-DIRECTION.md](STORY-DIRECTION.md). جميع التغييرات معزولة تحت `docs/motion/hyperframes/`، والدمج في الصفحة الرئيسية ينتظر موافقتك الصريحة.
