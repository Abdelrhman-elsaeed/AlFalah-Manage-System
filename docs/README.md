## How to use this spec kit
1. Read `00-PROJECT-OVERVIEW.md` before writing any code.
2. Before starting a phase, open the matching file in `phases/`.
3. Treat every entity field, endpoint, enum value, permission, and Arabic
   template as a hard requirement. Do **not** invent new restrictions unless
   explicitly requested; when unsure, choose the scalable safe approach and
   document it here.
4. After finishing a phase, update the **Change-log** below and the phase file
   status.
