# S0 — قرارات التشغيل المعتمدة

اعتمدها صاحب المشروع في الحوار بتاريخ 2026-10-03. المرجع المشترك [plan.md](../plan.md)، والسجل D-93.

| القرار | التنفيذ المطلوب / المرحلة |
|---|---|
| تنظيم المدرسة | مجلدان «مكتبة المدرسة» و«أرشيف الزيارات» تحت جذر Drive المدرسة المضبوط حاليًا؛ مجلدات المعلمين تبقى في مواقعها. S1 يثبت الهوية والحدود؛ S2 يهيئ المكتبة؛ S5 يهيئ الأرشيف. |
| عزل المجلدات الجديدة | فحص أن المجلدين لا يقعان داخل أي منح لمعلم، ولا أن منح معلم يشمل جذر المدرسة كله. إذا وجد تداخل يُرفض التفعيل مع تقرير للمسؤول؛ لا تُعدل المنحة تلقائيًا. |
| الحجم | حد الملف 250 MiB = 262,144,000 bytes، مع حدود النقل multipart/proxy المناسبة. يجب فصل حد الملف عن حجم الطلب الكلي في S2 لتقبل الحافة بالضبط. |
| الأنواع | الأنواع الحالية PDF/DOC/DOCX/PPT/PPTX/XLS/XLSX/JPG/JPEG/PNG، إضافة MP4/MOV/WEBP/HEIC. S2 يفحص النوع الفعلي والامتداد والاسم؛ لا يجعل وجود الامتداد دليل سلامة. |
| المعاينة | PDF/الصور/MP4 حيث يدعم المتصفح؛ MOV/HEIC وغير المدعوم يعرض بيانات الملف وتنزيلًا مصرحًا به. لا وعد بتحويل ملفات أو codecs جديدة في الإطلاق الأول. |
| الاحتفاظ | الملفات المعتمدة وكل PDF زيارة معتمد بلا حذف تلقائي في الإطلاق الأول؛ تبقى النسخ السابقة بعد التغيير أو إعادة اعتماد الزيارة. |
| حذف قبل الاعتماد | نقل غير المعتمد إلى مهملات Drive مع سجل حذف في SQL؛ الاستيفاء يسقط فورًا، وإعادة الطلب لا تكرر العملية. لا hard delete من النظام أو Drive. |
| تغيير بعد الاعتماد | طلب تغيير مع إبقاء النسخة/القرار الأصليين؛ لا تعديل مباشر أو نقل لمهملات Drive. تطبق القاعدة إذا كان أي رابط نشط معتمدًا؛ S3. |
| الملفات العامة | يرفعها المدير والمفوّض فقط. المسؤول الوظيفي عن مطلب لا يصبح مفوضًا تلقائيًا. |
| أصل واحد وروابط متعددة | نفس بايتات Drive لكل المهام والمعايير؛ قرار مستقل لكل رابط/سنة/سياق. |

## مدخلات تفعيل تبقى مطلوبة

- هوية كل مدرسة/سنة تشغيلية ومجلداتها الفعلية تُقرأ من إعدادات البيئة عند S1/S2/S5؛ لا تُخزن معرفات Drive أو أسرار Google في الوثائق.
- الاتصال الموجود في قاعدة Development ليس دليل اتصال حي؛ نتيجة محاولة القراءة في [drive-baseline.json](drive-baseline.json).
- تعيين مسؤولي البنود إلى مستخدمي المدرسة الفعليين، وتسوية اختلاف نسخ مصفوفة المصدر في S6؛ لا مطابقة آلية باسم شخص.
- الملفات الأصلية التاريخية غير متاحة في الحزمة الحالية. نقل القوالب والمطالب متاح؛ استيراد البايتات يظل مؤجلًا لحين توفير المصدر.

لم يُنشأ مجلد أو يُرفع/يُحذف ملف في S0. هذه قرارات للمراحل المالكة وليست تغييرات إعدادات نافذة الآن.
