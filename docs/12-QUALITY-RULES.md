# 12 — Quality Rules

**Status:** Baseline · **Last updated:** 2026-07-10

Follow these rules strictly:
- Keep code clean and maintainable.
- No business logic in controllers.
- No direct EF queries in controllers.
- Use application services.
- Use DTOs.
- Use validations.
- Use ApiResponse.
- Use global exception middleware.
- Use current user abstraction.
- Use async/await.
- Use cancellation tokens where appropriate.
- Use dependency injection properly.
- Use secure password handling through Identity.
- Do not store secrets in code.
- Keep Arabic UI labels in frontend translations.
- Keep technical code names in English.
- Add comments only when needed.
- Avoid microservices.
- Keep it as a layered modular monolith.
- **Stop after each phase implementation and report what was done.**
